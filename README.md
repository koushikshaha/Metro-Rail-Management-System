##  About the Project

The **Metro Rail Management System** is a web-based application designed to digitalize and simplify metro rail operations and passenger services. It is modeled with special relevance to the **Dhaka Metro Rail** system, making it practical and scalable for real-world implementation.

### Key Features
- Passenger registration and ticket booking
- Fixed fare display based on route and distance
- Train route and schedule management
- Employee assignment and shift management
- Maintenance logging and tracking
- Secure payment processing

---

##  Core Entities

| Entity | Description |
|--------|-------------|
| `Line` | Metro lines with start/end stations and distance |
| `Station` | Stations belonging to a line |
| `Train` | Train fleet with capacity and status |
| `Route` | Routes with distance and estimated duration |
| `Schedule` | Departure/arrival times and days of operation |
| `Fare` | Pricing based on route |
| `Passenger` | Registered passenger accounts |
| `Ticket` | Tickets linked to passengers and schedules |
| `Payment` | One-to-one payment records per ticket |
| `Employee` | Staff assigned to stations and trains |
| `Maintenance_Log` | Records of maintenance activities |
